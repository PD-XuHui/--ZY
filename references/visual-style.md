# 秩野Vibe视觉规范

## 固定风格

- 比例：3:4竖版小红书图文。
- 气质：克制、干净、低饱和、有男性杂志感，但不营造昂贵或距离感。
- 主色：米白、暖灰、暖棕；藏蓝、卡其、军绿可作为主题辅助色。
- 默认使用暖色系作为封面和正文的大面积底色，优先采用米白、奶油色、浅卡其与暖灰；对其效果的判断仍需账号数据验证。
- 黑色和炭灰仅用于标题、局部信息块或必要的对比，不再连续使用大面积黑色遮罩作为整组主视觉。
- 字体：中文以宋体风格为主，优先使用中易宋体或设备可用的等效宋体。
- 层级：主标题必须足够大、醒目；黑色负责主体信息，暖棕负责数字、关键词和步骤编号。
- 留白：保持呼吸感，但不能因为留白导致文字过小。

## 封面主体尺寸与缩略图验收

- 封面的核心人物、产品或前后对比，是点击率信息的一部分；先保证主体足够大，再安排留白和装饰。
- 按手机缩略图预览时，用户应能立刻看出主体、痛点或差异；若缩小后只剩标题清楚、人物或物品难辨认，必须放大主体或改用更近的裁切。
- 人物主题优先使用腰部以上、三分之二身或局部特写；只有必须说明整体比例、裤长、鞋型等内容时才使用全身。使用全身时，人物从头到脚宜占画面高度约60%以上，并避免把主体压缩在底角。
- 左右对比封面应让两侧主体都清楚可见；优先放大对比部位，不要用两个过小的全身人物代替关键差异。
- 标题需要空间时，调整文字区域、背景或裁切，不以缩小核心画面换取大面积空白。

## 排版规则

- 封面通常使用2–3行大标题，第一眼看清痛点、数字和结果。
- 正文页围绕一个主结论组织；可使用小标题和足以解释清楚的内容，按阅读负担决定要点数量和页数，不为压缩页数牺牲字号或解释。
- 重要判断标准用大数字、前后对比或局部放大表现，不依赖密集小字。
- 所有文字保留足够安全边距，并作为独立可编辑元素存在。

## 构图变化

不要连续使用“上方文字、底部横排物品”的单一构图。根据内容选择：

- 左右分屏前后对比；
- 中央主体配环形信息；
- 对角线展开；
- 三格或四格局部微距；
- 衣柜、镜面、工作台或时间轴场景；
- 大号数字与清单围绕中心排布；
- 同一人物正面、侧面和背面的多视图。

变化构图时仍应保持字体、色彩、留白和材质语言一致。

## 人物使用

- 木制人偶是秩野Vibe既有的品牌记忆点；根据内容优先考虑完整木制人偶、静物或示意图，不强行在所有封面放人偶。
- 用户已允许高精度手绘漫画风人物用于需要人物出镜的内容，并希望通过表现数据评估；这是可测试的视觉变体，不应宣称已经优于木偶。真人照片与高度写实摄影仍不作为默认方案。
- 用户为某篇明确选择漫画人物或极简线条人时，按当篇选择制作；人物表现不得与该篇已确认脚本冲突。
- 人物形象保持自然、普通、可信，避免明星感或过度精修；人物对比保持脸型、五官、年龄、光线及表情一致，不以偷换人物制造效果。
- 木制人偶必须有完整头部、躯干和四肢，不得出现无头、缺手、缺脚或异常关节。
- 服装应自然穿在木制人偶身上，保留真实面料、版型和叠穿关系，不能把衣服悬空摆放成“无头人”。
- 同一组对比应保持同一个木制人偶、镜头、姿势、光线和背景，仅改变需要解释的服装变量。

## 静物使用

- 服装、鞋、护理用品与配饰要服务于知识点，而不是成为装饰堆叠。
- 优先使用细节特写、材质对比、使用前后和场景化摆放。
- 生成提示词应明确：无文字、无数字、无品牌Logo、无水印，并为后期文字保留真正可用的区域。
