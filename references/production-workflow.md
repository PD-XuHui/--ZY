# 制作与归档工作流

## 1. 选题与数据依据

- 优先参考账号目录中最新的选题规划、数据复盘和已发布内容。
- 账号核心定位：帮助普通男生用低成本、可执行的方法改善整体形象；内容不局限于服装，可覆盖发型、眼镜、清洁、气味、体态、剃须、生活习惯和相关用品。
- 选题优先采用已经验证的结构：`具体痛点 + 数字清单/公式 + 低成本解决方法`。
- 正文必须兑现封面承诺，给出可以立刻检查或执行的标准。

## 2. 文案确认阶段

每个新选题开始时，在账号目录创建独立的本地选题文件夹，命名为 `账号目录/连续编号+选题名/`；文案、底图、成品页和可编辑源文件都归入该文件夹。

发布标题和封面文案统一遵循：

- 发布标题与封面主标题：`行动激励＋具体方法＋明确结果`。标题需要同时告诉用户为什么或何时行动、正文提供什么具体方法、执行后能获得什么明确变化。
- 封面小字：`用户痛点＋干货形式＋收藏理由`。优先使用“具体痛点｜清单/公式/步骤/判断标准｜男生收藏/建议收藏”的结构。
- 数字必须与正文一致，封面承诺必须由正文逐页兑现。避免只有情绪没有方法、只有问题没有结果的宽泛标题。

首次收到新选题时先输出：

1. 发布标题；
2. 封面上标、主标题和副标题；
3. 建议页数；
4. 每一页的标题、正文、强调句或清单；
5. 每页的核心画面方向。

文案应适合大字号排版。单页只讲一个核心结论，避免塞入过多长句。保存为：

`账号目录/连续编号+选题名/草稿/文案/选题名_图文文案_vX.X_待确认.md`

用户确认前不开始整组图片生成。用户只要求测试首图时，只生成首图，等其确认后再继续。

## 3. 设计制作阶段

- 在主题目录下按需建立：`草稿/底图`、`草稿/成品页`、`草稿/可编辑版`。
- 底图与文字分离。背景图不得包含任何生成式文字、数字、Logo或水印。
- 使用可编辑文本框完成中文排版；最终至少保留一份可编辑源文件。
- 当 Canva 不能直接创建完整布局时，可先制作 3:4 的 PPTX 可编辑版，再导入 Canva。
- 对比型选题优先呈现局部放大、错误/正确并列和明确标注，不要只依靠文字解释差异。

## 4. 检查与修订

逐页检查：

- 标题是否一眼可读，字号是否足够大；
- 封面在手机缩略图尺寸下，核心人物、物品或对比差异是否仍能一眼辨认；若主体偏小，先放大或裁切，再调整文字与留白；
- 正文是否超出安全区或被图片遮挡；
- 宋体、黑色、暖棕层级是否一致；
- 同一人物对比是否保持身份与镜头条件一致；
- 是否出现缺头、缺手、异常肢体、眼镜或剃刀变形、重复物品；
- 页面数量、顺序和文案是否与确认稿一致。

修改时创建新版本，不覆盖用户已经确认或发布的文件。

## 5. Canva 与保存

- 用户明确说“确认”“开始制作”时，可以进入设计制作阶段。
- 用户确认最终页面后，在对应选题目录创建“已确认版”文件夹，按顺序保存最终图片和发布信息，保留原稿；无需用户手动编辑时，默认交付本地确认版，不必上传 Canva。
- 每次上传或保存到 Canva 前，先展示该次拟上传的最终封面和内容页，等待用户明确确认本次上传；此前的上传授权或“开始制作／输出图文”等指令不等于本次上传确认。用户要求调整后，必须展示调整后的最终稿并重新获得本次确认。
- 导入后打开设计并确认：页面完整、文字可选中编辑、画布为3:4、所有更改已保存。
- 返回 Canva 编辑链接，并说明页数与可编辑状态。
- 最终页面确认归档后，或 Canva 确认保存后，必须在对应选题目录自动生成发布信息 Markdown 文件，不需要等待用户再次索要；若本地归档和 Canva 版本不同，明确标注。
- 发布信息文件命名为：`选题名_发布信息_vX.X.md`。不得覆盖旧版本；内容修改时递增版本号。
- 在选题根目录保留发布信息 Markdown；本地最终页面确认后，也在“已确认版”文件夹放置对应的发布信息，标明版本，方便直接取用。

## 6. 发布信息

最终页面确认归档后自动生成发布信息文件，内容包括：

- 建议发布时间：结合该选题的已确认文案及账号既有数据，写明建议日期、时间和时区，核对星期；标明属于待验证建议，最终发布时间由用户决定。
- 标题：继续满足`行动激励＋具体方法＋明确结果`，与封面一致但避免机械重复，可调整语序，并保留核心方法、数字和结果；标题不得超过20个可见字符，中文、数字、英文字母和标点均各计1个字符。该限制仅用于发布信息中的发布标题，不限制封面标题；
- 简介：先点出常见问题，再概括解决方法，最后加入低门槛收藏或评论动作；
- 话题：最多5个，优先选择4–5个与男生形象、具体痛点和内容场景直接相关的话题，避免无关热词和重复近义词。
- 评论区运营：结合本篇内容提供一条可直接使用的作者首评、开放式互动引导、针对不同读者反馈的回复示例，以及发布后检查与整理评论的简短安排。时间为可调整的运营建议，不保证效果；只提供草稿，不代表已发布或代用户评论。
- 归档信息：保存状态、设计页数；如已上传 Canva，提供对应版本的编辑链接。

## 7. 完成标准

一次完整任务通常包含：确认后的文案、独立主题文件夹、底图、成品页、可编辑源文件、本地已确认版和发布信息。需要 Canva 编辑时，在用户对本次上传明确确认后再上传并提供链接。仅当用户要求其中一部分时，按其范围交付。
