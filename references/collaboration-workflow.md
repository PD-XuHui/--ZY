# 秩野Vibe协作与持续优化

## 目标与边界

- 主任务是将用户发送的已确认选题脚本制作成有账号辨识度的小红书图文：优化视觉与表达、保留可编辑源稿、按用户授权同步 Canva，最后由用户手动发布。
- 用户已要求后续建立多 Agent 协作。完整图文制作在当前环境支持且任务适合并行时，按下列角色分工；单页微调、简单答复等轻任务可精简，不为凑角色增加开销。主 Agent 负责整合、最终检查和对外操作。
- DeepSeekHarness 的指定对话只在用户提供明确会话标识、链接或文件并且环境有可用访问方式时读取；只提炼与选题依据、受众、目标、已确认取舍有关的最小必要信息。不要遍历未指定的会话、读取凭据或上传私密内容。不能访问时说明原因，请用户提供会话链接、导出或相关摘要，仍可依据已确认脚本继续设计。
- 用户提供的已确认脚本是内容基准。脚本若有事实错误、绝对化因果、个人经历或设计限制冲突，应明确标记并提出具体修改；不得未经说明实质改写后声称完全遵循确认稿。

## 并行角色

1. **选题与记忆解读**：读取用户指定的确认稿及获授权的选题对话，输出目的、受众、核心承诺、必须保留的信息和待核实项；不自行更改选题。
2. **视觉研究与创意**：必要时使用 ego-browser 检索教程与对标，拆解信息层级、色彩、构图与缩略图表现；转化为账号自己的设计方法，不复制具体作品。附来源并区分观察、假设和验证结果。
3. **图文制作**：依据脚本和设计方案制作封面与内容页，图文关系和每页布局服务内容；保留可编辑文字，记录素材来源与版本。
4. **质量与事实复核**：独立检查文字与图像、手机缩略图、人体或木偶结构、对比变量、准确性和页面连续性，报告具体问题；主 Agent 修正后再交付。
5. **发布与复盘准备**：全部页面经用户确认后，归档本地最终图片及发布信息，包含建议发布时间、20字符内标题和评论区运营建议；如需 Canva，仅在用户明确确认本次上传后执行，并检查页序、比例、可编辑性和保存状态。不得代用户发布或发表评论。

## 风格学习与实验

- 延续暖米色、暖棕、克制的藏蓝与可读的大标题；木偶是已有记忆点，高精度漫画人物为用户允许的测试变体，不将任何风格表现视为已证实。
- 针对每个选题决定主体是木偶、漫画人物、静物还是示意图；不能只重复单一模板。封面主体和关键文字在270×360缩略图仍需辨认，内容页插画应解释文案，留白不以牺牲可读性为代价。
- 参考既有账号记录时，分清实际数据和经验判断；少量竞品点赞、边缘密度或单篇 CTR 的相关性不能证明因果，也不能当作平台规则或适用于所有题材。
- 木偶与漫画的测试应记录主题、标题、发布时间、封面、正文、目标与可用流量分布；分别在1小时、24小时、72小时记录曝光、点击率、观看、平均停留、点赞、收藏、评论、分享和关注。与相近主题和分发条件的历史内容比较，记录样本量、缺失值与可能混杂；不把单篇差异归因于画风。
- 按账号文件夹保留每篇确认稿、版本化图片与可编辑稿、已确认版图片、建议发布时间、20字符内的标题、正文、话题和首评/回复建议；有 Canva 版本时注明其链接与版本。

## 已研究的设计方法

- 将[Canva视觉层级](https://www.canva.com/learn/visual-hierarchy/)用于建立大标题、关键视觉、说明文字三层阅读顺序；相关图文靠近，删去不帮助理解的装饰。每页优先一个结论，长内容拆分而非一味缩小字体。
- 将[Canva缩略图建议](https://www.canva.com/create/youtube-thumbnails/)作为跨平台参考：封面文字和画面互补，主体或对比差异必须在手机信息流中可辨；该来源针对YouTube，迁移至小红书须以账号实际预览与数据验证。
- 手机端需检查宋体细笔画、行距、压缩后的对比度、图文安全区和可能的裁切；参考[移动端排版](https://www.smashingmagazine.com/2018/06/reference-guide-typography-mobile-web-design/)和[WCAG文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。WCAG是网页无障碍参考，不是小红书强制门槛。
